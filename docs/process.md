# 从参考拆解到公开 Skill：完整制作回顾

这套方法来自一次持续迭代：学习照片剪纸城市穿搭短片，先做人物与城市资产，再把上海、伦敦和巴黎做成多版作品。过程并非一次成功，下面保留真实反馈与改法。实际交付文件以 [媒体清单](../media/catalog.json) 为准，未导出的版本不冒充成品。

## 1. 从表面质感回到动作机制

最初判断是照片、抠图、平面图层和道具转场。校园试片只让单张人物进入画面，用户指出与参考不符。随后加密检查人物动作：参考抽查段中可辨认正面约4个主要姿态、侧面约6个，约1秒循环。它说明姿态有序切换与整体位移是两件事；不能据此断言原作者用了什么AI、软件或多少源PNG。

校园试片作为“仅有拼贴外观、缺少人物内部动作”的反例保留。之后先做人物动作图，再合成动画。相关观察见 [逐帧复核](../references/frame-audit.md)。

## 2. 人物一致性与脸部质量

蓝衬衫第一组人物图出现僵硬感、噪点和光斑。用户要求留存旧图但后续避免。红衣新参考被用作新的身份母图，先生成一组完整人物姿态；轮廓、脸、衣服与包须连贯。纸质效果放到边缘、底纸、城市贴图，不用随机噪点覆盖脸。

这一步抽象为：先锁主角，再改动作；不能把换姿态变成换人。已有合格资产就复用，不为流程重复生图。

## 3. 上海：从人物循环到城市生活

生成武康风格建筑、梧桐、街角咖啡、单车、咖啡杯、道路和路牌。用户强调原片纸边、报纸杂志剪字、轻微晃动，以及大幅贴纸从不同方向占满画面再转场。

上海 v2 使用 `Shanghai Citywalk`，不添加中文译名；出现的中文采用得意黑。四姿态循环与建筑、树、路牌、咖啡杯独立轻摆。不同道具分别从左、下、上、右方进入。记录了真实不透明覆盖检查，而非只判断图片矩形盖住画面。

这一步抽象为：材质、内部动作、图层运动和转场覆盖要分别设计。

## 4. 伦敦：半身、全身、细节与单元素转场

新主角穿荧光绿针织与深色短裤。用户要求每场换纸底，增加半身/全身等贴图尺度，参考时尚大片配色，转场缩减为单一纸片元素。首次走动仍不自然，进一步改为左右腿交换、包自然摆动。

两张图仍可能前腿未真正交换，故增加经过身体下方的第三张姿势。伦敦 v4/v5 使用 A→C→B→C。两帧版本和单独循环预览都收录用于对比，而非推荐所有项目都只用三帧。

用户再次要求回看原片、增加城市场景。伦敦 v5 新增斑马线、地铁入口、出租车、电话亭、花店书店和咖啡桌椅等。道路→建筑→地铁→车辆，街屋→道路→桌椅，形成逐件搭景，避免背景只是装饰。

伦敦 v2 有工作工程，但没有找到单独最终成片；仓库明确标为工程阶段，不伪造输出。其他可用最终片及已交付预览全部入库。

## 5. 巴黎：差异化镜头与步态纠错

用户要求8–10秒、奶油黄上衣女子、巴黎，并与前版镜头轨迹不同。设计9秒：

1. 奶油纸底，人物穿搭近景与腰部、咖啡细节卡。
2. 牛仔蓝纸底，人物斜向行进，街角建筑、地铁入口、塞纳河书摊分层贴入。
3. 巨幅巴黎明信片遮挡后缩小收拢，成为结尾收藏拼贴。

巴黎 v1 使用四张动作图，但人物腿部扭曲。旧实现还将下半身单独伸缩对齐，这种补偿不能修复错误解剖。用户明确要求正常左右往前走。

巴黎 v2 重新生成A（画面左侧腿前迈）、B（右侧腿前迈）、C（并腿经过）三张同人图；保持上半身稳定，取消所有独立腿部拉伸和循环中的身体倾斜。节奏为8/4/8/4输出帧，24fps一轮1秒。检查两轮和导出后的动作帧，保留旧版供对比。

这个改法适用于本次克制的正面剪纸走路；若要求侧面大步或更连续真实动作，需要不同的支撑/经过姿势，不能把共享C当成万能步态。

## 6. 从本地工程到可移植技能

保留原创作工程和所有去重图片，视频同时提供MP4与GIF。把模型参数、机器路径和特定渲染服务移出通用规则。原工程的HyperFrames/GSAP仅为一种实现，新增无动画框架的Canvas/JSON路径供有浏览器的agent使用。仅具生图能力的agent可交付资产包与精确时间线，但不能虚称已导出视频。

发布包不包含本机缓存、凭证、私有路径、macOS专有字体或原始参考视频的全片抽帧。原工程用系统字体回退，保留有开放许可的得意黑；已导出的历史成片不变。素材来源、字体替换和许可范围见 [来源说明](../ATTRIBUTION.md)。

## 可复用的判断

- 形式的核心是“主角动作循环＋逐件搭景＋道具带出换场”，不是纸纹滤镜。
- 动作是否成立先看图片，再看时间线。形变、溶解和加快播放无法掩盖错误腿部。
- 一个城市不能只靠地标：街道设施与生活道具把它变成vlog。
- 差异化来自镜头尺度、场景顺序、运动方向与收尾方式的组合。
- 检查过什么就说什么。音轨时长、电平和编码检查不等于听过。
