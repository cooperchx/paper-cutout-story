# Paris Citywalk

9 秒竖屏巴黎穿搭剪贴动画，1080×1920，24fps。

- 奶油黄穿搭近景与咖啡、腰部细节卡片。
- 牛仔蓝报纸背景，人物斜向行走，搭配街角咖啡馆、地铁入口、塞纳河书摊。
- 巴黎明信片占满画面后缩小收拢，落成结尾拼贴。
- 四张人物动作图循环，纸质边缘、轻微独立晃动；保留半身和全身等不同贴图尺度。

可编辑工程包含全部 PNG 素材、分镜、生成提示、HTML/GSAP 动画和原始合成音乐。assets/walk-A、P、B、Q 是四张行走图，其他四张 PNG 是城市贴图。运行 build.py 可从统一源码重新生成页面。HyperFrames 版本为 0.8.226。

音乐为本地合成，已检查音轨和音量，未进行人工试听。原有上海、伦敦版本保留。
