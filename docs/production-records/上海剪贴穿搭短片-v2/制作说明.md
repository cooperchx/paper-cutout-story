# Shanghai Citywalk · v2

12 秒竖屏短片，1080 × 1920，24 fps。上一版保留在相邻的「上海剪贴穿搭短片-v1」文件夹。

## 本次修改

- 保留四张人物动作图循环；人物、建筑、树、路牌和咖啡杯分别轻微摆动，节奏错开。摆动以每秒 8 次离散位置更新，保留纸片定格感。
- 4.55–6.31 秒：梧桐从左侧进入，巨型咖啡杯从下向上穿过前景，完全遮挡时切到咖啡店。
- 9.02–10.55 秒：店面从上方进入，巨型建筑从右向左扫过前景，完全遮挡时返回街景。
- 英文主标题固定为 Shanghai Citywalk，保留杂志剪字质感，不加中文译名。
- 其他中文统一使用得意黑（SmileySans-Oblique），包括重新排版的武康路路牌。
- 沿用原人物素材，本次没有重绘人物脸部，也没有给脸部叠加颗粒或光斑。
- 音轨为本地合成的原创器乐节拍，转场增加轻微纸张摩擦声。

## 验证

已检查 280 个正式人物帧的动作图显示状态，无缺帧或同时显示多张的问题。两次换景时的贴纸不透明区域完整覆盖画面。可阅读镜头的 97 项文字对比度检查通过，中文字体已加载确认。巨型贴纸遮挡期间，自动检查曾对已被盖住的文字报告对比度问题，经画面与覆盖范围核验属于遮挡误报。音频完成电平及时长检查，未作人工听感审核。
