# 上海散步 · 剪贴穿搭动画

成片：上海散步-剪贴动画.mp4。12 秒，1080×1920，24 fps，H.264 视频＋AAC 立体声音轨。

## 内容

- 使用已完成的红衣人物 A/B/C/D 四张姿态，每张保持 6 个输出帧，持续顺序循环。
- 上海纸质贴纸逐件搭建街景，单车从前景经过，街区横移后进入咖啡店场景。
- 文字采用独立字片：不同衬线/粗黑/打字机字形、米白/黑/锈橙纸片、微不规则边缘、轻微印刷磨损和错落倾角。
- 人物纸边在合成中添加，未重新生成脸部。纸纹只作用于背景和字片，没有覆盖到人物面部。
- 使用原创合成的轻节奏伴奏和短纸片落位声，无旁白；没有使用原参考视频的音乐。已验证音轨存在、时长和电平，未作人工听感评审。

## 工程

可编辑工程位于本目录的“可编辑工程”文件夹，入口 index.html，动画由暂停的 GSAP 时间线交给 HyperFrames 驱动。直接打开 HTML 不会自动播放完整时间线。

在工程目录运行 `npm run preview` 可打开编辑预览；`npm run render -- --output final.mp4 --fps 24 --quality high` 可重新导出。工程锁定本次已验证的 HyperFrames 0.7.103。

本次工作预览：http://localhost:3024/#project/shanghai-citywalk （服务运行时可用）。它指向工作副本；交付工程是导出时的独立副本。

## 验证

- HyperFrames 布局、运行时和动态检查通过；73/73 文本对比度检查通过。
- 人物出现后 280 个时间线帧逐一检查，均只有一张人物姿态可见。
- 成片共 288 帧。对编码后 268 个稳定显示帧检查红衣主体区域，未发现人物闪空；查看了开场、街景、单车经过、换场、咖啡场景和结尾的成片抽帧。
- 输出包含 12 秒 H.264 视频与 48 kHz AAC 音轨。
- 使用截图捕获、浏览器硬件 GPU 路径完成导出。原人物素材和已交付上海贴纸未被覆盖。

建筑为创意重绘，咖啡店为虚构场景，路牌是地点标识设计。
