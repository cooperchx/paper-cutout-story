# London Citywalk — 两张人物图循环版

15 秒 / 1080 × 1920 / 24 fps。

- 使用内置 image_gen 分别生成 A、B 两张人物 PNG，左腿前迈与右腿前迈交替；每张保持 8 帧，16 帧一轮。
- 手臂和包在两张照片中一起改变位置；保留剪纸定格节奏。没有关节纸偶、姿态形变或交叉溶解。
- 头部和上身位置保持对齐，B 图在网页合成中对短裤下方做轻微纵向映射，校准鞋底；源 PNG 原样保存。
- 两处转场均使用单个图片素材：伦敦巴士从侧面划过、伦敦主题报纸从下向上划过；遮满时切换场景。
- 保留纸边、轻晃、三种纸背景、全身/半身和局部拼贴。文案为 London Citywalk。
- 音轨沿用上一版原创合成节奏；没有进行人工听音评价。

人物两帧目录包含原始 PNG 和最终生成提示词。可编辑工程包含全部素材和时间线。

渲染器由 HyperFrames 0.7.103 更新到 0.8.226，新版本检查通过。用量查询返回 unknown（usage_request_failed），未推测剩余额度。
