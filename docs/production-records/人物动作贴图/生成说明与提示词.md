# 正面迈步：四张独立人物动作图

工具：内置 imagegen。每张为 1024 × 1536 RGBA PNG，保留生成的透明通道。

- pose-A.png：右脚向前接地（画面左侧）。
- pose-B.png：右脚支撑，左腿向前收步。
- pose-C.png：左脚向前接地（画面右侧）。
- pose-D.png：左脚支撑，右腿向前收步。

顺序：A → B → C → D → A。建议后续以每张 0.25 秒作为起始测试速度，根据实际循环观感调整。当前交付为人物动作素材，没有制作成片。

四张都保留了蓝衬衫、宽松牛仔裤、白鞋、挂在衣襟的眼镜和同侧黑包。存在生成式图像常见的衣褶、发丝与手部细节差异，后续合成仍需检查循环衔接。
