# 合成与运动方法

以下数值是便于开工的建议，不是对参考片工程的反推。按画幅、素材尺寸和主题修改。

## 资产分层

| 图层 | 常见内容 | 动作职责 |
|---|---|---|
| 纸底 | 低对比纸纹、单色纸 | 承载全场色调；通常保持稳定 |
| 远景 | 楼房、山、店面、货架碎片 | 慢移或依次贴入，不要全铺成写实风景照 |
| 地面 | 纸条道路、桌面、轨道 | 为主体提供落脚／摆放依据 |
| 中景道具 | 车辆、路灯、植物、商品配件 | 描述环境，偶尔经过人物后方 |
| 主体 | 人物、产品、动物、食物 | 最清楚的轮廓和最强的观看动机 |
| 信息 | 标签、纸卡、手写旁注 | 随阅读顺序出现，独立于主体图片 |
| 前景／转场 | 大车、大杯、信封、纸页 | 组织遮挡与场景切换 |

层级按实际遮挡关系调整，不是强制轨道数量。给每个素材记录 `id / path / type / alpha / anchor / scene / source_status`；给每段运动记录 `start / end / property / from / to / easing`。未获取素材时记录缺项，不填不存在的文件。

## 素材边缘

- 透明素材先在深浅两种底色检查，尤其是发丝、包带、鞋底、细长结构。白色背景不等于 alpha 透明。
- 1080 宽画面可从 4–10 px 浅纸边、2–6 px 投影偏移、低不透明度投影开始调整。缩放素材时要考虑最终输出上的描边宽度。
- 可用 alpha 膨胀得到纸边：`border = dilate(alpha, radius) - alpha`；主体、纸边和投影作为一组运动。薄纸感不需要很重的立体浮雕。
- 人物动作素材的轮廓必须随每帧变化；不要在静态轮廓里播放动作，也不要每帧随机扰动边缘。
- 保留轻微手工不齐，避免持续高频抖动。若需要停格感，可只量化选定图层到较低动作频率，成片仍以目标 fps 输出；这与故意让全片掉帧不同。

## 人物运动：按素材决定

复现 PAPER CITY 时先读 [逐帧复核](frame-audit.md)，优先采用下文 B 的离散姿态循环。A 是可选素材来源，不表示要追求连续自然步态；C 不能替代该参考的多姿态动作。

24 fps 的实现例：四姿态 `pose = floor((frame - startFrame) / 6) % 4`；六姿态 `pose = floor((frame - startFrame) / 4) % 6`。只在人物所属片段内求值；每次仅显示一张姿态，透明背景、同一画布，人物整体坐标另算。相邻姿态的头身比例、身体中心和地面基准需校准，不能每张按不同的非透明边界自动撑满画布。保持姿态切换的停格感，不默认加交叉淡化。

### A. 短动作抠像

适合接近参考片的步行、转身、整衣袖。拍摄或取得几秒、固定相机、背景易分离、全身不出框的动作。先做主体分割、边缘稳定和色彩统一，再进合成。循环处匹配姿态、位置与速度；若要交叉过渡，检查透明叠影，不能用重影掩盖明显跳步。

### B. 连拍／多姿态序列

同一人物、同一服装、同一视角，得到一个完整步态周期所需的姿态；可先从 6–12 张测试。保持画布、头部比例和脚底参考线统一。镜像会反转包、扣子和文字，不能随意当成另一条腿的动作。过渡不要依靠会扭曲衣服的形变。

### C. 静态纸偶／局部关节

只有一张图时，可做滑入、点跳、轻摆、局部手臂转动。用身体整体移动表达玩具感；对自然步行要求高时需要补姿态或动作素材，不承诺单张图平移等价。

### 锚点和位移

人物常以脚底中点为锚；切换姿态先对齐锚点。正面原地循环配合道路／场景移动可以成立。侧面行走若每周期前进距离为 `D`、周期为 `T`，世界位移速度可从 `D/T` 调整，并观察支撑脚在屏幕上的漂移。背景和人物相对运动要一起算，不只调人物 x 坐标。原地迈步也可作为明确的纸偶表演，但要保持视觉规则一致。

## 运动配方

- **贴入**：短位移＋少量旋转回正，必要时轻微缩放回弹。可从 0.2–0.45 秒试起；不要每张素材都大幅弹跳。
- **横向街景**：不同背景组以不同速度移动，重复素材在画外衔接；检查循环接缝，不让同一栋楼在主体旁突然出现。
- **小车经过**：简单匀速移动通常够用；无需为所有车轮制作真实旋转。
- **剪字拼装**：每个字／词一张纸片，略有字体、纸色、倾角差异；按可读的顺序进入。不要为了随机而破坏标题识别。
- **群像收集**：复用已出现人物，按阅读方向进场与排布；落位后留可读停顿。尺寸、遮挡和服装识别优先于整齐等距。

## 道具遮挡转场

先设计遮挡轨迹，再决定场景切换方式。

1. 将道具放在 A、B 两场之上，检查实际 alpha 轮廓。
2. 如果存在覆盖整个画幅的不透明区间，可在该区间直接切 A→B。
3. 如果车顶／车底或杯子两侧仍有空隙，使用与运动方向配合的揭示遮罩；把遮罩切换边界藏在道具的不透明区域内。不要在空隙尚可见时突然换底色。
4. 道具继续运动离场，露出 B；B 的主体和标签进入时间与揭示协调。
5. 在最大覆盖及其前后逐帧看，不能只看转场中间一张截图。

横移的公交、电车、行李箱，纵移的杯子、瓶子，展开的包装纸都可承担此职能。若为了填屏严重拉伸产品，改选遮罩或纸页转场。

## 纸页翻转

将 A 场全部可见层预合成为一页，B 在后面。以一侧或适当竖轴为支点，结合有限透视旋转和位移将 A 移出；处理背面可见性及旋转后的裁切。不必模拟复杂真实纸张卷曲。参考片约 32.8 秒的转场更接近整页绕竖轴转出。

## 工程与声音

AE／剪映等图形时间线或 Remotion／其他逐帧渲染框架均可。选择当前环境真正可用且支持透明素材、蒙版、分层变换和导出的工具；FFmpeg 适合抽帧、转码和简单叠加，复杂场景不要强行塞入不可维护的滤镜链。

动画由时间或帧号确定，避免依赖运行时随机状态。定稿后渲染首尾帧、转场密集段、人物循环接点，再验完整片。文件存在不能代替播放检查。

音乐长度、节拍和音效需实际监听；听不了就不判断原片音轨。读标签所需的停留比强行每个鼓点切场更重要。
