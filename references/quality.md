# Review and local fixes

Review a representative composite and two subject cycles before expanding the asset set. Final checks use the encoded artifact, not merely file existence or the authoring preview.

| Check | Failure | Appropriate correction |
|---|---|---|
| A/B leg identity | Same leg forward twice | Regenerate opposite phase; describe anatomical and screen side |
| Passing pose | High knee / crossed ankles | Reduce stride; relaxed near-vertical legs |
| Source anatomy | Bent/twisted pants | Regenerate image, remove limb deformation |
| Alignment | Head changes size or jumps | Stable canvas and uniform whole-subject transform |
| Identity/outfit | Cup/bag/face changes | Edit from approved master; reject drift |
| Alpha | White rectangle/glow/fringe | Confirm alpha on light/dark ground; segmentation or photo-card route |
| Border | Border frozen while pose changes | Derive edge from each pose alpha; stable physical texture |
| Feet | Large uncontrolled sliding | Reconcile pose timing, path and contact cue; reduce movement |
| Paper feel | Heavy plastic bevel | Thin irregular pale border, modest shadow, matte ground |
| Motion hierarchy | Everything shakes at once | Keep ground quiet, stagger local moves, reduce amplitudes |
| Place | Generic poster | Add streetside activity objects and staged scene assembly |
| Wipe | New scene flashes in holes | Actual-alpha cover test or reveal mask |
| Typography | Tiny, unreadable, clipped | Fewer words, larger type, safe margins, longer hold |
| Ending | Cut before landing | Land elements early enough to read final state |
| Audio | Missing/clipped/mismatched length | Measure stream, duration and peak; listen if tool permits |

A silhouette can be read anatomically in a contact sheet, but that does not prove motion is pleasing. Inspect the loop at speed when playback is available. Distinguish visual inspection, numeric checks and listening in the delivery note. A portable baseline can keep the face static during gait, but should not claim expressive full-body acting.

Use start/end and dense samples around each scene cut. Example: at cut T inspect T−0.2, T−0.1, T, T+0.1, T+0.2 seconds, plus any faster edge event. Label requested sample times as samples rather than exact edit boundaries.

Retain prior versions. Record user feedback and the specific change, not an unsupported “perfect” score. Some historical examples in this repository are intentionally imperfect; follow the documented correction, not every visible artifact.
